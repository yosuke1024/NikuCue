# Claude Code に渡す開始指示

以下を、仕様パックを置いた新規プロジェクトのClaude Codeに渡す。

```text
このフォルダのREADME.mdとCLAUDE.mdを読み、docs/以下とJSON契約に従って
正式採用したアプリ名「NikuCue」のiPhoneアプリを実装してください。
Appアイコンは「肉球」をモチーフにしてください（`docs/14_APP_ICON.md`参照）。
旧ブランド名は使用せず、猫の呼び名Mali（มะลิ／マリ）は維持してください。
企画提案をやり直すのではなく、この仕様を初期決定として扱ってください。

最初に既存ファイル、git状態、macOS/Xcode/Swift/Simulator環境を確認し、
既存コードや未コミット変更を壊さない作業計画を docs/IMPLEMENTATION_LOG.md に書いてください。
次にTask P00とP01から着手してください。
本番用アプリアイコンはP12で完成・検証してください。最初のデモ段階は暫定アイコンでも構いません。

最初の縦切りは、ネット通信なしの猫デモです。
1匹の猫が呼吸・まばたき・しっぽの動きをし、タップで甘え、
デモの「できた」で1.6秒程度喜ぶところまでを動かしてください。
仮の幾何図形だけを完成キャラクター扱いしないでください。
仕様に沿ったパーツと顔を作り、実機/Simulatorで画像と動画を記録してください。
描画部分とイベント・状態ロジックを分離し、後から絵を差し替えられるようにしてください。

実行時AI、独自バックエンド、Firebase、外部分析SDK、RevenueCat、
常駐監視、他アプリへの重ね描画、有償アニメーション編集ツール、
遠隔設定・素材ダウンロードは導入しないでください。
課金はStoreKit 2の広告削除1商品だけ、広告はAdMobバナー1枠だけです。

各タスクで、実装→実行可能なテスト→差分レビュー→実装ログ更新まで進めてください。
試せなかった項目を成功扱いせず、コマンド・結果・未実施理由を分けて記録してください。
コード署名/ストア/広告の本番IDがなくても、Mockまたは公式テスト設定で
ローカル開発を進めてください。実IDを推測したり他アプリのIDを流用しないでください。
承認前の公開・本番広告配信・課金設定変更・GitHubへのpushは行わないでください。
猫の見た目とタイ語は人間の確認項目として残し、それ以外の実装を進めてください。
```

## 開発環境がない場合

Xcodeがない環境ではiOSビルドを成功扱いしない。移植可能な仕様、ソース、純粋ロジックのテストを進め、macOSで必要な手順と未実施項目を残す。iPhoneへの配布には署名やApp Store Connect/TestFlightの操作が必要であり、仕様ファイルだけで自動的に配布できるわけではない。
