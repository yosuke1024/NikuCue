# 14. NikuCue Appアイコン制作仕様（肉球）

## 1. 決定事項とスコープ

- アプリ正式採用名: **NikuCue**。旧Pix系ブランド名をアプリ名へ付けない。
- iOSホーム画面／App Storeのシンボルは**猫の肉球**。猫Maliの全身像、写真、カメラ、レンズは描かない。
- ロゴ・アイコン自体にアルファベット、タイ文字、日本語、Q/Cueの文字を入れない。
- この文書は**制作指示**であり、完成したアイコン画像ではない。
- 最終の商標・類似デザイン調査とYohによる視覚承認は公開ゲートに残す。

## 2. デザインコンセプト

**一つの大きな肉球パッド＋四つの指球。** かわいく、静かで、押しつけない印象。肉球のシルエットは64px程度の縮小表示でも一瞬で分かること。アプリ内の猫Maliと同じ色世界で統一する。

デザイン初期案として以下を推奨（厳密な色固定ではなく、ブランド内の参考値）：

- 背景: クリーム `#F4E2C8` か薄いアイボリー `#FFF8EF`、不透明な単色。
- 肉球パッド: やさしいキャラメル `#C98E62`、必要なら内側の淡いピンク `#DC9292` を少量。
- 形: 大きい下部パッド1つ＋上部の小さい指球4つ。連結・境界が潰れないように。
- 表現: シンプルな面。細い輪郭線、光沢、写実的な毛並み、手書き風の小さいディテール、長い影は不要。
- 他社アプリのロゴをトレースしない。独自の曲線、間隔、余白を用いる。

## 3. 制作・実装要件

1. ソースを編集可能な形（SVGまたはベクターパス生成コード等）で保管する。外部素材の権利に依存しないオリジナル図形で構成する。
2. 1024×1024px・正方形・sRGBの**不透明**PNG（アルファなし）へ書き出す。角丸は画像に焼き込まずiOS側に任せる。
3. Xcodeの`Assets.xcassets/AppIcon.appiconset`に構成し、`Contents.json`と実際の採用ターゲット設定を確認する。使用中のXcodeが要求する形式に合わせ、架空のスロット定義は作らない。
4. App Store提出用と同じアイコンを、180px、120px、60px、40px相当でプレビューし、肉球と分かるか確認する。
5. Light/Dark表示で読みやすさを確認。多色のalternative iconsや着せ替え・季節ごとのアイコンはv1では実装しない。
6. 生成スクリプトがある場合は誰でも同じPNGを生成できるよう、生成手順を記録する。AI生成画像を採用する場合でも利用条件・独自性・編集可能な元データの確保を別途確認する。

## 4. 受入条件

- 背景は不透明、端まで塗られている。四隅へ角丸の余白を二重に描かない。
- 肉球の五つのパッドが数えられ、指球が文字やドットに見えない。
- 60px程度でも肉球だと分かり、アイコンの中に小さな説明文字を置かない。
- インストール画面／ホーム画面／設定におけるアプリ名は`NikuCue`で統一。
- スクリーンショット、編集元ファイル、PNG、生成工程、ライセンス情報を成果物に含める。
- 最終承認が得られるまでは`R14: 未完了`とし、「ロゴ完成」や「公開可能」とは報告しない。
