# 02. 機能仕様

## 1. オンボーディング

O01: 猫が座り、短く自己紹介。「はじめる」「まず会ってみる」。会ってみるは記録を作らないデモ。
O02: 猫の呼び名。初期値はMaliの各言語表記。任意変更。空白のみ不可、最大16拡張書記素。絵文字・タイ語を壊すbyte切りは禁止。
O03: 最初の習慣をテンプレートか自由入力で作る。テンプレートは「水を飲む」「少し体を動かす」「少し読む」「机を整える」「自分の習慣」。水分量・運動量を医学的に処方しない。
O04: 通知の価値と、曜日・時刻を選ぶ画面。「設定する」「今はしない」。OS権限は設定するを押した場合だけ要求。[S05]
O05: Home。作成途中は下書きを端末に保存し、クラッシュ後に再開できる。初回一巡には広告・販売ダイアログを出さない。

## 2. 習慣

必須は名前（1〜40拡張書記素）、カテゴリ（water / stretch / read / tidy / custom）、対象曜日。
曜日はISO月曜=1〜日曜=7としてdomainで保持。毎日は7曜日の集合。

- 追加: 選択曜日に今日が含まれれば今日から対象。含まれなければ次の該当日。
- 5件有効なら追加ボタンから説明を表示。購入リンクは出さない。
- 名前・カテゴリの変更は即時。履歴表示名も現行名を使う（名前履歴は保存しない）。
- 曜日の変更は翌日から。今日/過去の予定と達成率を後付けで書き換えない。
- アーカイブは翌日から。今日は「今日は休む」で終えられる。UIに「明日から表示しない」と明記。
- 再開は新しい適用日から対象曜日を登録。アーカイブ期間を遡って未達にしない。
- 並び替えは有効な習慣内で可能。反応の優先順には影響しない。
- 完全削除は設定/編集の二段階確認。関連記録と予定版を削除。累計日数を再計算する。

## 3. 記録

予定対象日のhabitId + dayKeyが一意キー。1日に何度押してもdoneの記録は1件。

| 状態 | 記録上の意味 | 主な操作 |
|---|---|---|
| pending | 対象日だが記録なし | できた / 今日は休む |
| done | 本人ができたと記録 | 取り消す |
| skipped | 本人が休むと選択 | できた / 休みを取り消す |
| notScheduled | 対象外 | 操作なし |

OSによる行動の自動検知はしない。チェックは自己申告。医療的・科学的な正しさの証明には使わない。

書込の順序は入力検証 → 単一actor内でidempotent保存 → 集計 → UI表示 → 猫イベント。失敗時は元状態を維持し、保存エラーを表示。再試行しても二重加算しない。

done操作直後に10秒の「取り消す」を表示。トーストが消えても履歴から直近7日内なら訂正できる。取り消しで悲しい演出をしない。猫はニュートラルへ戻る。

## 4. 履歴と集計

- 直近7日は「今日を含む7日」。未来日・作成前・予定外・アーカイブ期間は編集不可。
- 過去の訂正は通常の保存フィードバックのみ。大きなお祝い・触覚・再訪イベントを出さない。
- 今日の進捗: `done / scheduled`。skippedは別に「休み」と表示し、doneに加算しない。
- 予定ゼロ日は`0/0`を見せず「今日は予定なし」。全達成イベントを発生させない。
- 全部done: allDone。すべてdoneまたはskippedだがskippedを含む: allResolved。「全部達成」と偽らない。
- 一緒にできた日: 1件以上のdoneがあるdistinct dayKey数。習慣数では加速しない。休みだけの日は加算しない。非連続でも積み上がる。
- 履歴は予定の版を参照し、当時の対象日を再構成する。

3/7/14日の節目は日数に応じた特別な反応のみ。衣装・機能の解放はない。節目表示済みIDは取り消しで消さず、同じ節目の演出を何度も得ることを避ける。完全リセット時は消す。

## 5. 今日の休み / 再訪

習慣ごとの休みを用意する。全部を休むボタンは初期版に追加しない（誤タップと状態数を減らす）。全件skippedでも猫が苦しむことはない。

前回foregroundのdayKeyから3日以上空いた最初のHome表示でwelcomeBack。達成回数に関係なく歓迎。回数の少なさを言及しない。一日に何度開いても長い歓迎を繰り返さない。

## 6. なでる

猫を1回タップすると短いpet反応。2秒間はpetの重複を無視する。なでる操作は習慣達成にも累計日数にも加算しない。VoiceOverでは「猫をなでる」ボタンとして提供。

## 7. 保存・バックアップ

習慣、曜日の適用履歴、記録、猫の呼び名、表示設定、節目表示済みIDを端末保存する。クラウド同期用のentitlementを付けない。[S03]

手動バックアップは`nikucue-backup-v1.json`。JSONは暗号化されていないことを共有前に示す。Files/Share Sheetを本人が選んだ場合のみアプリ外に渡る。OSの通常の端末バックアップにアプリデータが含まれる可能性はあるが、独自同期・復元保証はしない。

復元: 5MB上限、schemaVersion検証、型・ID・日付・文字数・参照整合性・重複・件数を検証 → 内容件数をプレビュー → 現在データを書き出す選択肢 → 二重確認 → 一括置換。自動マージしない。失敗時は元DBを維持。購入権利・広告同意・テストフラグ・端末ID・診断ログはバックアップに含めない。

削除/復元後は通知を再構成する。復元した通知は必ずOFFで開始し、本人が再有効化する。未承認の通知や広告同意をインポートしない。

## 8. 設定

猫の呼び名、言語、触覚、動きを減らす、通知、購入/復元、広告のプライバシー設定、バックアップ、ヘルプ/不適切広告の報告、プライバシー、全データ削除。

「全データ削除」は習慣・キャラ・履歴・診断・節目を削除し通知解除、オンボーディングへ戻る。StoreKit購入権利は保持。SDK同意の変更はプライバシー設定、OS通知権限はiOS設定で扱う。消して再購入させない。
