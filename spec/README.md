# NikuCue — Claude Code 開発開始パック

仕様 v1.1（名称・アイコン更新のみ） / 作成日 2026-10-10 / 対象: iPhone先行

**猫が習慣を見守り、小さな達成を一緒に喜ぶ。猫の世話を新しい義務にしない。**

このパックは実装前の設計・データ定義・文言・検証基準です。動作するiOSアプリ、完成した猫のイラスト、アニメーション動画、ストア登録を納品したものではありません。

## 決定一覧

| 区分 | 決定 |
|---|---|
| ユーザー確定条件 | iPhone先行。猫好きのタイ人のパートナーに最初に使ってもらう |
| 実行時の構成 | AI・独自サーバー・有償APIなし。習慣と記録は端末保存 |
| 収益モデル | 無料版にバナー1枠。非消耗型の買い切り購入で広告削除 |
| 今回の設計決定 | SwiftUI + SpriteKit + SwiftData + UserNotifications + StoreKit 2 |
| 初期対応 | iOS 17以降を設計上の下限。iPhone、縦向き。実機・採用SDKの対応を着手時に検証 |
| 言語 | タイ語・英語・日本語。タイ語の実機確認を公開ゲートにする |
| スコープ | 猫1匹、部屋1つ、最大5つの有効な習慣、定型反応、履歴、ローカル通知 |
| ブランド | **アプリ名 NikuCue（採用）** / 猫 Mali（มะลิ、マリ）。商標・App Store登録可否は公開前に確認 |
| Appアイコン | **肉球のシンボル**。文字・カメラモチーフなし。`docs/14_APP_ICON.md`に制作仕様 |
| 費用の定義 | 追加の自前バックエンド/AI/API従量費ゼロ。開発者登録・ストア手数料・保守工数は別 |

広告・課金はGoogle/Appleへの通信を伴います。「通信なし」「外部送信ゼロ」という宣伝にはしません。広告が出ない状態でも習慣と猫は動作させます。

## 最初の成果物

アプリ名はNikuCue、アイコンは肉球。カメラ・写真モチーフやPixの冠は用いない。

最初は習慣一覧でも広告SDKでもなく、**猫が呼吸する → なでると反応する → 達成を喜ぶ**の実機デモを作る。その後の機能実装は並行して進めてよいが、見た目の承認前に衣装・別の猫・複雑な演出を量産しない。

## 仕様の優先順位

ユーザー確定条件 > CLAUDE.mdの禁止事項 > 各専門仕様 > JSONの具体値 > 一般的な実装慣習。
文章とJSONの不整合を見つけた場合は、勝手に片方を無視せず修正して根拠を記録する。公開名・ID・価格・SDKバージョンの仮値は実装用の本番情報として扱わない。

## パックの整合性検証

`python3 scripts/validate_pack.py`で同一キー・placeholder・パーツ参照・反応ID・基本の文字数制約を確認できます。作成時は169キー×3言語、26ノード、8クリップ、16反応ルール、40件の未実施QAシナリオの検証を通過しています。結果はPACK_VALIDATION.json。これはiOSの実行テストではありません。
