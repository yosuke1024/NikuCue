Mali（マリ）リグ・プレビュー

NikuCue の猫キャラクター Mali を、iOS アプリと同じ JSON 契約（character_spec / mali_paths / animations）からブラウザで描画した確認用ページです。猫をタップすると「なでる」反応、ボタンで各クリップと表情を再生できます。

これは開発用プレビューで、iOS アプリや Simulator の録画ではありません。絵はコード描画の試作（承認待ち R02）です。

反応（デモ）

全クリップ（8）

表情（5）

表示設定

64px での見え方（静止画）

仕様との対応

idle
呼吸 3.6 秒・胴 ±1%・しっぽ ±5°・瞬き 4〜7 秒
celebrate
1.6 秒：予備動作 → 小さく跳ぶ（+34）→ 着地 → 嬉しい顔
pet
0.9 秒：頭を 7° 傾け目を細める。2 秒間は連打無視
milestone
2.2 秒：2 段階の喜び + ハート最大 3 つ。全画面演出なし
Reduce Motion
跳躍・ハートの動きを止め、表情のクロスフェードのみ
